# 数据分析作品集｜Data Analysis Portfolio
## 👋 关于我
前报价师转行数据分析，熟悉报价与客户转化业务。
掌握 Excel、SQL、Power BI、Python，擅长从业务角度做数据分析，挖掘问题并输出可落地优化方案。

## 📁 项目目录
- **project1：报价业务转化分析**
模拟企业报价业务，分析报价转化情况，定位影响成交的关键因素，搭建PowerBI交互式看板，辅助评估报价策略。

- **project2_customer_churn：客户流失分析**
模拟询价场景客户流失数据，统计流失原因与行业流失率，使用DAX实现指标计算，定位高流失群体，输出客户留存方案。

## 🛠️ 技术栈
Python(Pandas/Faker)、MySQL(SQL)、Power BI(DAX、数据建模、可视化)、Excel

## 📌 项目亮点
1. 业务贴合：基于报价岗位真实业务经验设计场景，分析结论具备落地性
2. 完整分析闭环：Python生成模拟数据 → SQL探索分析 → PowerBI可视化 → 业务洞察与优化建议
3. DAX实战：CALCULATE、TREATAS、DIVIDE等上下文计算
4. 交互式看板：支持切片器下钻筛选细分维度
